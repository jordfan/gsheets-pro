why this shape

A capable agent does not need a hundred verbs. It needs feedback.

Every response is prose plus structured data. Every error carries a code, a message, and a hint that names the fix. Every write ends with a read of what it touched. The four panels below are real output, not descriptions.

Thirteen tools, shaped like tasks

Sheet names and A1 ranges everywhere; the server resolves ids and grid indexes. One batch update per call, field masks built from the arguments you passed, backoff on the quota.

openreadwritetablesettingsstylevalidationconditional_formatstructurefindbatchcheckrender

Errors it can act on

A refusal is information. This one comes back when a write would land on a formula, with or without any setup on the sheet.

code "formula_guard" message "D14 currently holds a formula. Writing here would replace it." hint "Read the cell, decide whether you meant to, then pass force."

It can see its own work

A lint of seven rules reads the API, not the pixels, and each finding names the call that fixes it. A render turns a tab into a PNG the agent looks at, once, before it says done.

rule L09 error range 'Roster'!1:1 message No frozen header row. fix sheets_style { sheet: "Roster", sheet_props: { freeze_rows: 1 } }

It says no when nobody is watching

A registry in your repository names the spreadsheets other people depend on. A hook checks it before every call, asks on a laptop, and in an unattended run denies with the reason, because an unanswered prompt just stalls.

"sort" would change the row order of Private lessons, and the registry marks its row order as load bearing. Other people's formulas and printed copies point at those row numbers. Append at the bottom instead, and leave existing rows where they are.
what it cannot do

Stated plainly, because the agent will find out anyway.

  • Named functions and Apps Script are out of reach of the Sheets API.
  • Dropdown chip colors cannot be set or read. Rewriting a rule a person built wipes theirs, so the plugin refuses.
  • A render never draws a dropdown as a pill. The lint is the authority on validation.
  • The export used for rendering is undocumented by Google; a whole-workbook fallback exists.
  • Setup needs your own Google Cloud OAuth client, about 25 minutes, and you must click Publish or the token expires in seven days.
  • Hosted mode has no confirmation dialogs; destructive changes are refused with a reason instead.
  • A one-call workbook builder and a formula pretty-printer are v1.1.
install

Three places it runs.

Laptop stdio

The skill, hooks, and presets, plus the bundled server. Then run the setup skill for the OAuth walkthrough.

claude plugin marketplace add jordfan/gsheets-pro
claude plugin install gsheets-pro@gsheets-pro gsheets-pro-local@gsheets-pro

A repository that runs in the cloud vendored

Cloud sessions load a repository's own skills and hooks but not a plugin declared in its settings. This copies them in and merges the hook entries; commit the result.

npx gsheets-pro vendor .

A server your team shares http

Stateless HTTP behind a bearer, with a Dockerfile and a hosting guide in the repo. Point a cloud session's .mcp.json at it.

GSHEETS_PRO_TOKEN=… npx gsheets-pro serve --http
