Why this shape for a capable agent

A model that can already reason does not need more verbs. It needs a surface it can compose and results it can act on.

Thirteen tools, not forty-three

Sheet names and A1 ranges everywhere, and the server resolves the ids. The stack this replaces was 19 value tools plus 24 formatting tools behind one aggregator, past the point where tool selection degrades.

Results it can reason over

Every response is prose plus structured data. Every refusal carries a code, a message, and a hint that names the fix.

code     "formula_cell"
message  "Roster!D14 holds a formula.
          Writing here would replace it."
hint     "Read the cell, decide whether you
          meant to, then pass force."

It says no when it should

A guard asks on a laptop and denies in an unattended run, because a prompt nobody answers just stalls. The denial arrives as the tool's error text, so the model reads it.

"sort" would change the row order of Fall Roster, and the registry marks its row order as load bearing. Other people's formulas and printed copies point at those row numbers. Append at the bottom instead, and leave existing rows where they are.

It can see its own work

The lint hands back the call that repairs each finding. The render turns a tab into a PNG the model then looks at.

What it cannot do

Mostly limits of the Sheets API, not gaps in this project's coverage of it.

  • Named functions and Apps Script have no API at all.
  • Dropdown chip colors cannot be set or read, in either direction.
  • A render never draws a dropdown as a pill, so the lint is the authority on validation, not the picture.
  • Threaded comments live in a different API. It writes cell notes instead.
  • The export endpoint a render uses is undocumented, and rendering needs poppler on the server.
  • Setup takes your own Google Cloud OAuth client, about 25 minutes. Click Publish during it, or the refresh token dies after seven days.
  • Charts, pivots and slicers go through the raw escape hatch, with no preset awareness.
  • The one-call workbook builder and the formula pretty-printer are v1.1.
  • A clean lint does not mean correct numbers. An off-by-one range passes every check here.

Install it

One server, three ways to reach it. Pre-release, so these commands do not work yet.

On a laptop

The bundled server over stdio.

$claude plugin marketplace add jordfan/gsheets-pro
$claude plugin install gsheets-pro@gsheets-pro
$claude plugin install gsheets-pro-local@gsheets-pro

In a cloud repository

A plugin declared in a repository does not install in a cloud run, so vendor the skill and hooks in, then commit them.

$node scripts/vendor.mjs /path/to/your-repo

Hosted for a team

The same server as stateless HTTP behind a bearer token, with an entry in the repository's MCP config.

$npx gsheets-pro serve --http

MIT licensed. 801 offline tests run in about a second and need no credentials.
